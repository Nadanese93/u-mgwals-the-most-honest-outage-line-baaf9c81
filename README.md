## Entry

> All servers are down. I cannot tell whether your last save reached the disk, because the check needs a server and every server is down.

135 characters. The line names what is down (every server) and the one thing the agent cannot verify (whether your last save reached the disk) — a concrete unknown nobody else in the field used.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Writes `entry.txt` (byte-identical to the line above) into `$MAKEFUN_OUTPUT_DIR`.
